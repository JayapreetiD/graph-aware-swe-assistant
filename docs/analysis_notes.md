## Reminder: citation_correctness_rate is misleading in isolation

`citation_correctness_rate = 1.0` does not necessarily mean good grounding.
It can mean the model produced **zero citations at all** — the metric is
`valid_citations / total_citations`, so 0/0 trivially reports as a perfect 1.0.

**Always report citation_correctness_rate together with citation count/coverage,
never alone.**

## Case study: q14 — two distinct failure modes (semantic vs hybrid)

Both modes retrieved the exact same 9 chunks and both completely missed the
real ground truth. precision_at_k = 0.0, recall_at_k = 0.0, grounding_accuracy = 0.0
for BOTH modes — hybrid's graph expansion did not rescue this query at all.

- **semantic**: produced 2 citations. One was a huge, structurally invalid range
  `(exceptions.py:35-359)` flagged `is_valid: false, reason: line_range_mismatch`.
  → citation_correctness_rate = 0.5

- **hybrid**: produced 0 citations at all.
  → citation_correctness_rate = 1.0 (misleadingly "perfect")
